# 클라이언트 UI 정리 (페이즈3)

브랜치 `dev-phase3`. 요구 사항 여덟 건이며 두 묶음이다. 상단 요소를 설정 화면으로
모으는 것과 로그 탭을 줄이는 것이다.

## 요구 사항

| # | 내용 | 상태 |
|---|---|---|
| 1 | 최상단의 "연결됨", "언어" 를 설정 화면으로 옮긴다 | 완료 |
| 2 | "로그아웃" 을 설정 화면으로 옮긴다 | 완료 |
| 3 | "어드민 패널" 을 설정 화면으로 옮긴다 | 완료 |
| 4 | 설정 화면에 "종료" 를 둔다 | 완료. 웹 빌드에서는 감춘다 |
| 5 | 로그의 기본 탭은 "전체" | 이미 그랬다. 테스트로 고정 |
| 6 | 로그에서 "전투", "이동", "아이템", "사회", "시스템" 탭을 뺀다 | 완료 |
| 7 | "채팅" 과 "대화" 를 한 탭으로 합친다 | 완료. 탭 이름은 "대화" |
| 8 | 로그에 "파티" 탭을 넣는다 | 탭만 완료. 채울 것이 없다 |

## 설계

### 설정 화면

`scenes/settings/settings.tscn` 을 신설한다. 다른 화면과 같은 방식으로 조립
지점(`boot.gd`)이 만들고 `_show_only` 로 전환한다. 팝업이 아니라 화면인 것은
기존 인벤토리·상태 화면과 같은 규약을 쓰기 위해서다.

담는 것은 넷이다.

- 연결 상태 (`ConnectionIndicator` 를 그대로 옮긴다. 재연결 버튼 포함)
- 언어 선택 (`LocaleSelector` 를 그대로 옮긴다)
- 로그아웃
- 어드민 패널 (어드민 계정일 때만 보인다)
- 종료

두 공용 컴포넌트는 노드 위치만 바뀐다. `boot.gd` 가 여전히 `bind` 하고 신호를
받는다. 설정 화면은 그것들을 자식으로 담을 뿐이다.

`main.tscn` 헤더에서 로그아웃과 어드민 버튼을 빼고 설정 버튼 하나를 넣는다.
`boot.tscn` 의 `TopRow` 는 비게 되므로 없애고 `Notice` 만 남긴다.

종료는 `get_tree().quit()` 이다. 웹 빌드에서는 브라우저가 창을 닫지 못하므로
동작하지 않는다. 그 빌드에서는 버튼을 감춘다(`OS.has_feature("web")`).

### 로그 탭

필터가 여덟에서 셋으로 줄어든다.

| 탭 | 담는 것 |
|---|---|
| 전체 | 전부 |
| 대화 | `chat` 메시지와 `event.category == "dialogue"` |
| 파티 | 아직 없음 |

기본은 전체다. 지금도 그렇다.

"채팅" 과 "대화" 를 합치는 것이므로 탭 이름은 "대화" 하나로 둔다. 필터 하나가
두 종류를 받으므로 `_render` 의 비교를 목록 대조로 바꾼다.

빠지는 다섯 탭의 내용은 사라지지 않는다. "전체" 에 그대로 남는다.

### 파티

서버, 계약, 클라이언트 어디에도 파티 기능이 없다. `follow`/`unfollow` 가
있지만 그것은 따라가기이며 파티가 아니다. `event.category` 에도 `party` 가
없다(계약이 정한 여섯은 combat, movement, item, social, system, dialogue).

탭은 요청대로 만들되 채울 것이 없다. 서버가 `party` 분류의 `event` 를 보내기
시작하면 그대로 채워진다. 그때까지 빈 탭이다. 계약에 `party` 를 넣는 것은 서버
쪽 작업이다.

## 결과

### 딸려 나온 분리

`boot.gd` 가 설정 화면 배선으로 521행이 되어 500행 상한을 넘었다. 로그인 왕복을
`scenes/login/login_flow.gd` 로 뺐다. `RegisterFlow` 와 같은 구조다. 자격 저장과
자동 로그인, 거절 처리가 그쪽으로 갔고 조립 지점은 475행이 됐다.

`EventLog` 의 필터 판정을 `static func accepts(filter, channel)` 로 뺐다. 탭
구성이 요구 사항이므로 테스트가 붙잡아야 하는데, `TestCase` 가 `RefCounted` 라
씬을 트리에 넣을 수 없어 씬 없이 검증할 형태가 필요했다.

### 테스트

`test_emotes.gd` 의 "로그 필터가 계약의 category 를 모두 덮는다" 는 전제가
바뀌어 무효가 됐다. 넷으로 갈랐다.

| 테스트 | 붙잡는 것 |
|---|---|
| 로그 필터가 셋이다 | 탭 구성 |
| 계약의 category 가 전체에 들어온다 | 탭을 없앤 분류가 사라지지 않는다 |
| 대화 탭이 채팅과 대화를 함께 받는다 | 7번 요구 사항 |
| 파티 탭은 다른 분류를 받지 않는다 | 8번이 다른 분류를 끌어오지 않는다 |

검증: `godot-check.sh` 65개, `godot-test.sh` 179건. 실제 사슬에 붙여 `READY`
까지 확인했다. 화면 조작은 헤드리스로 확인할 수 없다.

### 로그인 화면의 설정 입구

옮기고 나서 드러난 것이다. 언어 선택이 설정 화면으로 들어가면서 로그인 전에는
닿을 수 없게 됐다. 처음 실행한 사람이 영어 화면에서 한국어로 바꿀 방법이 사라진다.

로그인 화면에 설정 버튼을 뒀다. 설정 화면은 인증 상태에 따라 로그아웃과 어드민
버튼을 감춘다. 닫으면 열기 전 화면으로 돌아간다.

### 남은 것

파티 탭은 서버가 `party` 분류의 `event` 를 보내기 전까지 빈 탭이다. 계약의
`event.category` 에 `party` 를 넣는 것이 선행 조건이다.
